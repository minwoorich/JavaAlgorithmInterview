## 1. 코드
```java
import java.util.*;

class Solution {
    public int solution(int[] priorities, int location) {
        int answer = 0;
        
        PriorityQueue<Integer> queue = new PriorityQueue<>((s1, s2) -> s2-s1); // 우선순위 큐 : 내림차순
       
        for(int i=0; i<priorities.length; i++){
            queue.add(priorities[i]); // 큐에 프로세스들을 옮겨담는다
        }
        
        while(!queue.isEmpty()){
            for(int i=0; i<priorities.length; i++){
                if(queue.peek() == priorities[i]){ 
                    queue.poll();
                    answer++;
                    
                    if(i == location){
                        return answer;
                    }
                }
            }
        }
        
        return answer;
    }
}
```

### 2. 우선순위별로 프로세스 탐색


- ``priorities[]`` 를 반복 문으로 순회하면서 우선순위가 높은 순 부터 차례로 탐색을 실시한다.
- 우선순위가 가장 높은 값을 찾았다면 큐에서 해당 프로세스를 제거한다.
- 제거함과 동시에 프로세스가 실행되었음을 ``answer`` 를 1씩 증가 시킴으로써 저장해놓는다.
- 만일,  ``location`` (찾고자 하는 프로세스의 위치) 에 도달한경우 ``answer`` 를 return 해준다.
